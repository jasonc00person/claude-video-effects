# Claude video effects

This folder is a free skill that makes 17 video effects on the user's own talking-head footage. Everything is in
`.claude/skills/video-effects/SKILL.md`: read it and follow it.

- On a new computer, always start with its Step 1, the setup check.
- The user is most likely a creator, not a coder: plain words, one step at a time, no jargon.
- Make the user's effect projects in their own folder (default `~/video-effects/<name>`), never inside this repo, so updating
  the skill never touches their videos.
- If they asked you to install it from a link, the steps are at the bottom of `README.md` ("For Claude: installing this skill").
